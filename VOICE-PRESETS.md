# Voice presets — 110 named archetypes

A preset is a **feature bundle** with a name (feature vocabulary: `seeds/README.md`, 58 scales).
Request one in chat:

- *"new character with a **noir detective** voice"* → audition a pair, you pick, 4-language pack built
- *"re-voice drake as **deadpan**"* → same character, new timbre
- *"**daddy** voice but **drier** and a touch **gravelly**"* → presets + raw feature tweaks mix freely
